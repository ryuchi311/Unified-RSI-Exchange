🎯 WHAT HAPPENS WHEN YOU START
════════════════════════════════════════════════════════════════════════════════

BACKEND (Port 5005):
  1. Connects to 4 exchanges (BingX, LBank, MEXC, Bitunix)
  2. Fetches 10,000+ perpetual futures trading pairs
  3. Subscribes to real-time kline (candlestick) data
  4. Calculates RSI on 5-minute and 15-minute intervals
  5. Detects when BOTH timeframes cross alert thresholds
  6. Broadcasts alerts to frontend via WebSocket
  7. Auto-reconnects if exchange connection drops

FRONTEND (Port 5175):
  1. Loads React dashboard with dark theme
  2. Connects to backend via WebSocket
  3. Receives live alerts in real-time
  4. Displays alerts with color coding:
     • Yellow = Overbought (RSI > 80)
     • Red = Extreme Overbought (RSI > 90)
     • Blue = Oversold (RSI < 20)
     • Purple = Extreme Oversold (RSI < 10)
  5. Allows filtering and chart control
  6. Shows exchange scanner status

🔧 TROUBLESHOOTING QUICK FIX
════════════════════════════════════════════════════════════════════════════════

❌ "Port 3000 already in use"
   ➜ Edit: frontend/vite.config.ts
   ➜ Change: port: 3000 → port: 5174

❌ "Port 3001 already in use"
   ➜ Edit: backend/.env
   ➜ Change: PORT=5000 → PORT=5001

❌ "Node.js not found"
   ➜ Install from: https://nodejs.org/ (v18+)
   ➜ Restart terminal after installation

❌ "npm ERR! Could not find Node.js"
   ➜ Restart terminal
   ➜ Verify: node --version

❌ "Module not found" errors
   ➜ cd backend && npm install --legacy-peer-deps
   ➜ cd ../frontend && npm install --legacy-peer-deps

❌ "WebSocket connection failed"
   ➜ Verify backend is running (http://localhost:3001)
   ➜ Check browser console for errors
   ➜ Check backend console for connection logs


📋 STEP-BY-STEP START
════════════════════════════════════════════════════════════════════════════════

1. Choose startup method (see "READY TO START" above)

2. Run script:
   • PowerShell: .\start.ps1
   • Batch: start.bat
   • Bash: ./start.sh

3. Wait for servers to start (~10 seconds):
   • Backend window will appear
   • Frontend window will appear
   • Browser may auto-open to http://localhost:3000

4. Dashboard loads:
   • See "Live Alert Feed" on left (initially empty)
   • See "Exchange Scanners" in center (4 columns)
   • See "Chart" at bottom (BTC/USDT default)

5. Click "START" button:
   • Turns green
   • Backend starts WebSocket subscriptions
   • All exchanges begin scanning

6. Watch alerts stream in:
   • New alerts appear in the feed
   • Color-coded by type
   • Click to see on chart
   • Auto-updates in real-time
