🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

"Port 3000 already in use"
  → Edit frontend/vite.config.ts and change port to 3002

"Port 3001 already in use"
  → Edit backend/.env and change PORT=3002

"Node.js not found"
  → Install from https://nodejs.org/ (requires v18+)

"npm ERR! Could not find Node.js"
  → Restart terminal after installing Node.js

"Module not found errors"
  → Run: npm install --legacy-peer-deps (in both backend & frontend)

"WebSocket connection failed"
  → Verify backend is running on port 3001
  → Check browser console for errors
  → Check backend console for connection logs
